Frequently Asked Questions

Is TauOS open-source?

Core components will be open-source; security-critical components and cloud services may be partly proprietary initially. We'll publish an OSS roadmap.

Does TauOS run Android apps?

We support compatibility layers for select Android apps where needed, but our goal is native cross-device apps built on the Tau SDK.

How private is TauCloud?

End-to-end encrypted. AES-256 storage, RSA-4096 / ECC P-384 for key exchange. Zero-knowledge by design for user data unless explicitly shared.

When can I pre-order?

Pre-booking is open now (fill the form). Shipping windows and serial numbers will be confirmed in follow-up emails.

What's included with TauCloud Premium?

Unlimited cloud storage, priority sync, advanced security features, and early access to new TauOS features.

Can I develop apps for TauOS?

Yes! The Tau SDK allows you to build once and run everywhere. We offer fair revenue splits and developer-friendly tools.

Interested in partnering or investing?

We're building TauOS for the long run. If you're an investor, partner, or enterprise interested in early collaboration, please contact our Partnerships & Investor Relations team.
