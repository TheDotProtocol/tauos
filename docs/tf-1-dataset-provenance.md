# TF-1 — Dataset Provenance Model

**Status:** Implemented in validation pipeline (TF-1)

---

## Core question

Every record must answer:

- **Where did this come from?**
- **Who created it?**
- **Was it generated?**
- **Was it transformed?**
- **What license applies?**
- **Has it been reviewed?**
- **Can it legally be used for training?**

---

## Provenance types

| Type | Meaning | Training eligibility |
|------|---------|-------------------|
| `TAU_CREATED` | Authored by Tau under contribution policy | Yes if `REVIEWED` + `CLEAR` |
| `THIRD_PARTY_LICENSED` | External source with verified license | Yes if license permits train + commercial |
| `THIRD_PARTY_TRANSFORMED` | Derived from licensed third-party via documented transform | Yes if transform + license allow |
| `TAU_SYNTHETIC` | Generated by model/API | Only if reviewed + legal clearance |
| `EXTERNAL_DATA` | External with incomplete audit | Block until classified |
| `UNKNOWN` | Not auditable | **Never enters dataset** |

---

## Legal status

| Status | Meaning |
|--------|---------|
| `VERIFIED` | Engineering audit complete — not legal counsel |
| `UNKNOWN` | Not yet audited |
| `REQUIRES_LEGAL_REVIEW` | Do not use for public model release without counsel |

---

## License status

| Status | Meaning |
|--------|---------|
| `CLEAR` | Permitted for intended use (train + commercial target) |
| `UNKNOWN` | Not audited — blocks promotion to train |
| `REQUIRES_LEGAL_REVIEW` | Counsel required |
| `RESTRICTED` | Limited use — document constraints |
| `NOT_PERMITTED` | Must not train — validator rejects |

---

## Review workflow

| Status | Meaning |
|--------|---------|
| `UNREVIEWED` | Draft — do not include in gold promotion |
| `REVIEWED` | Passed human or engineering review |
| `REJECTED` | Excluded — validator rejects |

Quality checks: factuality, usefulness, constitutional compliance, duplication, safety, licensing, formatting.

---

## Synthetic data rules

1. `provenance.type` must be `TAU_SYNTHETIC`
2. `synthetic: true`
3. `creationMethod: SYNTHETIC_MODEL_GENERATION`
4. `generatorModel` must name the generator (e.g. `qwen2.5-7b-instruct`)
5. `legalStatus: REQUIRES_LEGAL_REVIEW` by default
6. Never use benchmark prompts for synthetic generation destined for train
7. Synthetic output is **not automatically Tau-owned**

---

## Ownership honesty

| Claim | Valid? |
|-------|--------|
| "Tau authored this record" | Only for `TAU_CREATED` with `TAU_AUTHORED` source |
| "Tau owns all training data" | **No** — third-party and synthetic may impose limits |
| "Tau owns the dataset curation work" | Yes — schema, validation, selection, transforms |
