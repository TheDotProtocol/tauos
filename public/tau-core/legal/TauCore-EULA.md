You may choose a privacy level during setup:

| Level | Description |
|-------|-------------|
| **Maximum Privacy** | No system monitoring. Zero telemetry. |
| **Balanced Privacy** | System-level security events only. No personal data access. (Recommended) |
| **Enhanced Safety** | Extended threat and stability monitoring. System-level only. |

Monitoring, if enabled, is limited to CPU/memory/disk metrics, failed login attempts, malware signals, and network anomalies — never file contents, messages, or browsing history.
